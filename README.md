# ТурбоДроп

Браузерный симулятор кейсов. Всё оружие, скины, обложки кейсов и звук генерируются кодом.

- `src/` — исходники (CSS, разметка, модули JS по порядку загрузки)
- `tools/build.mjs` — сборка в один файл `dist/index.html`
- `tools/verify.mjs` — проверка шансов (сумма 100 000 билетов), RTP 88–94% и 10 000 симулированных открытий каждого кейса
- `tools/accept.mjs` — приёмочный прогон: деньги, дубли, сохранение, миграция v3, работа без localStorage, прокрутка 1000 предметов
- `tools/gallery.html` — галерея всех видов оружия и скинов
